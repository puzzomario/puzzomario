## 🚀 Featured Projects

### 🤖 Pneumonia Detection with Artificial Intelligence

**Bachelor's Thesis — 2025**

An AI-based system for the automatic classification of chest X-ray images for pneumonia detection.

**Technologies:** `Python` `TensorFlow` `Keras` `CNN` `Gradio`

The project involved dataset preprocessing, balancing, train/validation/test splitting, data augmentation and model optimization using Early Stopping and learning-rate reduction.

The trained model was integrated into an interactive Gradio application capable of receiving X-ray images and providing an automated prediction with a confidence level.
